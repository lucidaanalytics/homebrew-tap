# Lucida Homebrew tap

```sh
brew install lucidaanalytics/tap/lucida
lucida version
```

Installs the `lucida` CLI from its [GitHub releases](https://github.com/lucidaanalytics/lucida-cli/releases) on macOS and
Linux (x64 and arm64). The formula is generated from each release's `checksums.txt`. Guide:
<https://lucidace.com/help/install-cli>.
